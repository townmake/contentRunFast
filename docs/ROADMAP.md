# 路线图（摘要）

| 期 | 重点 |
|----|------|
| **MVP** | 选品 Listing 只读 + 导入工作台 + AI 出图候选 + 美客多发图/回滚 + 手工效果 |
| **二期** | Shopee/TikTok 商品适配；实验任务；广告读数；可选优胜回写选品 |
